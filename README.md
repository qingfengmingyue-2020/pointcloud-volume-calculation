# Point Cloud Volume Calculation – C++ Implementation
This repository contains four standalone C++ programs that compute the volume of a point cloud using different methods:
1. **Slice-based method** (proposed) – `1Code_for_point_cloud_volume_calculation_based_on_slicing_method.txt`
2. **Convex Hull** – `2Code_for_point_cloud_volume_calculation_based_on_Convex_Hull_algorithm.txt`
3. **Poisson Surface Reconstruction** – `3Code_for_point_cloud_volume_calculation_based_on_Poisson_Surface_algorithm.txt`
4. **Marching Cubes** – `4Code_for_point_cloud_volume_calculation_based_on_Marching_Cubes_algorithm.txt`
All programs use the **Point Cloud Library (PCL)** and are written in C++.
---
## Requirements
### Operating System
- **Windows** (tested on Windows 10/11)  
- Linux (Ubuntu 18.04+ or similar) should also work with minor path adjustments.
### Compiler
- C++11 (or later) compatible compiler  
- **Visual Studio 2019/2022** (on Windows) or **GCC 7+** (on Linux)
### Required Libraries
| Library | Minimum Version | Purpose |
|---------|----------------|---------|
| **PCL (Point Cloud Library)** | 1.9.1+ | Core point cloud I/O, filtering, surface reconstruction, convex hull, etc. |
| **Boost** | 1.60+ | Dependency of PCL (thread, system, filesystem) |
| **Eigen3** | 3.3+ | Linear algebra (bundled with PCL) |
| **CMake** | 3.10+ | Build system (recommended) |
> **Note**: On Windows, the easiest way to install PCL is via the **All-in-one installer** (available from the [PCL GitHub releases](https://github.com/PointCloudLibrary/pcl/releases)). It includes Boost, Eigen, and all dependencies.
---
## Installation Guide
### Windows (Visual Studio)
1. Download and install **PCL-1.12.1-AllInOne-msvc2019-win64.exe** (or a version matching your Visual Studio).  
   - During installation, check the option to add PCL to the system `PATH`.
2. Install **CMake** from [cmake.org](https://cmake.org/download/).
3. Open the solution (`.sln`) generated by CMake or create a new Visual Studio project and add the source file.  
   - For each `.txt` file, rename it to `.cpp` and add it to your project.
### Linux (Ubuntu/Debian)
Install PCL and its dependencies via `apt`:
